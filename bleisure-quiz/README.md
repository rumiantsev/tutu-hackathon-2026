# Bleisure-калькулятор — квиз (вариант подбора по «вайбу»)

Отдельная версия виджета: вместо плоского списка отелей — **квиз-вопрос «Какие у
тебя выходные?»** с коллекциями, в которые можно провалиться и посмотреть детали.

Текущее демо `bleisure-widget/` не затронуто — это самостоятельный вариант в
`bleisure-quiz/`.

## Отличие от основного демо

- Транспорт + сплит «компания vs сотрудник» — те же.
- Отель подбирается через **4 коллекции**: 💎 Лакшери / 🧖 Спа и wellness /
  🚶 Погулять по центру / 💰 Бюджетно.
- Клик по коллекции → дрилл-даун (пагинация по 5, аккордеон, карусель фото).

## Коллекции и данные

| Коллекция | Правило | Источник |
|---|---|---|
| 💎 Лакшери | `stars ≥ 4` | листинг |
| 🧖 Спа и wellness | `search_hotels(hotel_amenities=['spa','sauna','jacuzzi'])` | +1 поиск |
| 🚶 Погулять по центру | парсим `address` «N м/км от центра» → ≤ 600 м | листинг |
| 💰 Бюджетно | 4 самых дешёвых | листинг |

Пустые коллекции отбрасываются (не показываются).

## Запуск

```bash
cd bleisure-quiz
node server.js
# http://localhost:8081
```

Переменные: `TUTU_MCP_URL` (по умолч. `https://mcp.tutu.ru/mcp`), `PORT` (по умолч. `8081`).

## Деплой на Vercel

- `../api/bleisure-quiz.js` — serverless-функция (`/api/bleisure-quiz`).
- Демо: `/bleisure-quiz/demo.html` (редирект `/quiz` в `vercel.json`).

## Файлы

- `bleisure.js` — расчёт: транспорт + коллекции + спа-поиск.
- `server.js` — локальный dev-сервер.
- `widget.js` / `widget.css` — фронт (квиз → коллекции → дрилл-даун).
- `demo.html` — форма + виджет.
