# tutu-hackathon-2026 · Bleisure-калькулятор

Встраиваемый B2B-виджет, который превращает командировку в мини-путешествие
(**bleisure** = business + leisure) и считает раскладку расходов
**«компания vs сотрудник»** на живых данных поиска Tutu — сравнивая все типы
транспорта (самолёт / поезд / автобус) и подбирая отель на выходные.

> 🔗 **Прототип**: `https://tutu-hackathon-ott.vercel.app/`
> 🔗 **Репозиторий**: `https://github.com/rumiantsev/tutu-hackathon-2026`

## Что делает

Сотрудник едет в командировку и продлевает её на выходные. Виджет:

1. Сам определяет, как продлить поездку: конец в ср/чт/пт → вернуться в
   воскресенье; начало в понедельник → приехать в субботу.
2. Сравнивает рабочий и «личный» билет по всем доступным типам транспорта.
3. Показывает, сколько платит **компания** (рабочий билет), а сколько —
   **сотрудник** (доплата за билет + отель на выходные), и экономию компании.
4. Даёт готовые ссылки на покупку билетов и отеля на Tutu.

Два режима показа отелей: **«Список»** (рекомендация + альтернативы) и
**«Квиз»** (коллекции под вайб: 💎 Лакшери / 🧖 Спа и wellness /
🚶 Погулять по центру / 💰 Бюджетно).

## Технологии и инновационность

- **MCP (Model Context Protocol) как источник живых данных.** Виджет читает поиск
  Tutu через `https://mcp.tutu.ru/mcp` по JSON-RPC — без выделенного REST API и
  без ключей доступа, только read-only поиск и deeplink-ссылки на покупку.
- **Zero-dependency** — только стандартная библиотека Node 18+ (`fetch`), без
  сборки и lock-файлов; быстрый cold start на serverless.
- **Dumb frontend** — вся логика на бэкенде, виджет переиспользуем в любом
  host-приложении (интранет, HR-портал) через `<script>` + `data-атрибут`.
- **Serverless Vercel** — один общий вычислительный модуль для dev-сервера и
  продакшена.

## Быстрый старт

```bash
cd bleisure-widget
node server.js
# http://localhost:8080
```

Требования: Node.js 18+. Внешних зависимостей нет.

## Деплой на Vercel

Корень проекта — папка `tutu` (`.git` и `vercel.json` здесь):

- статика `bleisure-widget/*`;
- `/` → `bleisure-widget/demo.html`, `/quiz` → `bleisure-quiz/demo.html`;
- `/api/bleisure`, `/api/bleisure-quiz` → serverless-функции.

Переменная окружения (опционально): `TUTU_MCP_URL` (по умолчанию
`https://mcp.tutu.ru/mcp`).
